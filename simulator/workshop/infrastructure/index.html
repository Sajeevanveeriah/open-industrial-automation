Routed requests use source zone, destination zone and service. Replies follow established sessions. A switch cannot enforce this inter-zone policy on local frames.

Host services and addressing
Dynamic Host Configuration Protocol (DHCP) leases the highest available host addresses in the server subnet. Discoveries stay on the local VLAN. Domain Name System (DNS) records follow installed asset IDs. Network Time Protocol (NTP) copies the reference server offset.

Cell control and reporting
A programmable logic controller (PLC) reads one digital input per one-second teaching scan using a Modbus TCP register model. An OPC Unified Architecture (OPC UA) read returns the count to the gateway. Message Queuing Telemetry Transport (MQTT) delivers its queued observation to a broker. Each button executes one transaction; no wire encoding or vendor runtime is involved.


Read low, high, high and predict the count. Poll the tag, disconnect the inter-switch uplink, then count again. Is the last displayed value still trustworthy? Reconnect, poll again and deliver the queued observation twice with the first acknowledgement lost.

Model boundaries and references
This bench emulates IPv4 forwarding across access and trunk links. Loop-free forwarding uses a shortest-hop tree. The ARP and path cache expires after 60 simulated seconds. There is one inter-VLAN router per path. A trunk forwards the intersection of its end allowlists. Stream capacity subtracts configured background flows that have an available echo path. Video clips are timestamped metadata, and backups preserve that register. No host commands, live video or industrial networks are accessed.
Read the ARP specification, private address allocation and NIST guide to operational technology security.
