Network assurance and camera survey

Break an uplink, observe individual frames and commission a recorded field of view.

Commission a resilient cell

Begin with a worked parallel pair or a three-switch ring. Use the rack editor to build a different addressing plan, move endpoints or patch a standby. The control path must cross your selected uplink before the fault and carry traffic again within your chosen deadline. Failover tests run on a copy of your current wiring.

How restoration is measured
For each VLAN the bench selects a deterministic loop-free tree by cable ID. Equal-capacity parallel trunks can form one logical link. A flow hash selects its member, so an individual flow uses one member. This is a teaching approximation of ring protection and link aggregation. Member loss incurs the configured detection delay. A new tree also incurs the forwarding delay. Probes are issued at your interval. The first reply includes the round trip across the surviving links.


Watch a frame, then a group
Predict which hosts receive an unknown destination. Send a first unicast, return a reply to learn the address, and send the same frame again. The mirror copies traffic in either direction on one switch port. Internet Group Management Protocol (IGMP) snooping limits data to branches leading to subscribed hosts. Choose the listeners and compare flooded and snooped traffic.


Neighbour discovery and precision time
Assign a unique IPv6 address and prefix to each endpoint. Test an on-link peer, then deliberately duplicate an address. Precision Time Protocol (PTP) estimates offset with four timestamps. Predict the residual error when the outward delay exceeds the return delay.


Industrial traffic timing
Compare cyclic PROFINET real-time frames, EtherNet/IP implicit producer updates and a polled Modbus TCP exchange. Keep the producer period fixed. Increase competing frames per period and compare first-in, first-out (FIFO) service with strict priority quality of service (QoS). The shared bottleneck is the slowest link in the selected route.
Serial gateway framing
Build a Modbus RTU request from unit, function and data bytes. A universal asynchronous receiver/transmitter (UART) sends a start bit, eight data bits, optional parity and stop bits. Predict its wire time and the required 3.5-character silence. Try a parity mismatch.


Mount and aim a camera
A synthetic detection target has a known physical feature width. Change the camera mount, yaw and lens to resolve that feature and exclude the restricted point. The pinhole projection uses a horizontal floor plane, square pixels and constant bitrate. An operational clip also needs a powered camera, a reachable recording server and authorised viewing.


Restricted recording and door incident
Operations reports an uncertain emergency-egress event. Preserve the retrievable clip. The IT custodian restricts recording groups to include investigator and exclude visitor. Refer the physical door decision to the facilities lead. A different duty engineer must witness retrieval before handover. Keep the physical exit and all identities synthetic.


Documentation and model limits
This bench forwards frame metadata and emulates queue timing. One frame takes bytes × 8 ÷ link rate, plus 5 µs per link and 20 µs per intermediate switch. Timing includes a single congested egress queue. PROFINET, EtherNet/IP and Modbus TCP use illustrative 96, 128 and 110 byte frames. A poll adds a 95 byte return and 0.5 ms server turnaround. No protocol certification, video of people or physical egress actuation is involved. IPv6 covers unicast, prefix comparison, duplicate-address detection and solicited-node discovery on the local link. IGMP membership is explicitly set by the learner; no membership timer is emulated.
